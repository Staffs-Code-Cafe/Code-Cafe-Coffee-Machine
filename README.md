# ☕ Code Café Discord Bot

Welcome to the official **Code Café Discord Bot** — built for the **University of Staffordshire** tech and programming community!  
This bot is designed to make the Code Café server more interactive, organized, and engaging for developers, students, and tech enthusiasts alike.  

---

## 🚀 Features

### 👋 Community & Moderation
- **Welcome messages** for new members with university flair.   (Coming Soon)
- **Role assignment** (e.g. Year group, Course, or Skill level).  (Coming Soon)
- **Profile tracking** For members to showcase their skills and contributions.  (Coming Soon)
- **Event reminders** for Code Café meetups, hackathons, and workshops.  (Done)

### 💻 Developer Tools
- **Code snippet formatting** — cleanly share your Python, C++, JavaScript, and more.  (Coming Soon)
- **Coding challenges** — weekly problem-of-the-week announcements and leaderboard tracking.  (Done)

### ☕ Social & Engagement
- **Daily coffee quote** to kickstart your day.  (Warning: Very sarcastic)  (Done)

---

## 🧩 Commands

| Command | Description |
|----------|-------------|
| `/help` | Displays the list of available commands and usage. |
| `/events` | Lists upcoming Code Café events. |
| `/challenge` | Shows the current weekly coding challenge. |
| `/profile` | View your Code Café stats and activity. |
| `/github` | Fetch GitHub repo link. |
| `/quote` | Get a random coffee quote or motivational message. |

*(More commands can be customized in `commands/` directory.)*

## ⚙️ Setup

### 1. Clone the repository
```bash
git clone https://github.com/your-username/code-cafe-bot.git
cd mainBuild
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```
*Note:*
if pip is not pathed don't forger to use
```bash
python -m pip install -r requirements.txt
```

### 3. Configure environment
Create a `.env` file from the .env.example (Instructions included):
```
DISCORD_TOKEN=your_discord_bot_token_here
```

### 4. Run the bot
```bash
python main.py
```
